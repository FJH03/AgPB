# AgPW 3D 路点编辑工具

独立的 3D 路点辅助工具。它读取 `.agpw` 路点、BSP 地图和游戏模型资源，在本机浏览器中显示基础贴图地图、物件和路点，并可切回灰模；不接入 AgPB 插件，也不参与插件构建或部署。

支持路点半径与 Flags 编辑、保存 / 另存为及撤销 / 重做。地图和模型资源继续只读，路点位置与连线暂不开放修改。编辑状态、字段校验、命令历史和字节导出分别组织，便于后续扩展。

## 启动

需要 Python 3.10 或更新版本，以及支持 WebGL 的现代浏览器。Python 仅使用标准库；界面依赖的 Three.js 已随工具附带，运行时无需安装 npm 包或联网下载资源。

双击 `agpw_view3d.bat` 后，在首页点击“导入 AGPW”选择任意 `.agpw` 文件。工具读取文件头中的地图名，通过 `gameinfo.txt` 的 GAME SearchPaths 查找 `maps/<地图名>.bsp`；找不到就直接显示缺图错误，不自动加载 office 或其他默认地图。可在界面中反复导入文件来切换地图。默认游戏内容目录仍从仓库 `AGENTS.md` 的部署目标读取；也可用 `--game-dir` 指定。

把 `.agpw` 文件拖到启动器，或在命令行显式传入文件，也可以直接打开对应场景。

```powershell
py -B tools/agpw_view3d.py
py -B tools/agpw_view3d.py "D:\waypoints\cs_office.agpw"
py -B tools/agpw_view3d.py "D:\waypoints\cs_office.agpw" --game-dir "O:\SteamLibrary\steamapps\common\czero-game-x64\cstrike"
```

可用 `--bsp <地图.bsp>` 显式指定地图。`--game-dir` 是包含 `gameinfo.txt`、模型资源和 `maps` 的游戏内容目录，不是插件目录。把工具复制到其他位置时，保留入口、`agpw3d_bsp.py`、`agpw3d_models.py`、`agpw3d_materials.py`、`agpw3d_document.py` 和整个 `agpw3d_web` 目录，并显式传入文件和游戏目录即可。

启动后保留控制台窗口，浏览器通过随机地址访问仅绑定 `127.0.0.1` 的本机服务。关闭控制台或按 Ctrl+C 结束工具。`--no-browser` 仅打印地址，不自动打开浏览器；`--port` 可指定端口。

## 查看

- 环绕模式用左键旋转、Shift + 左键平移、滚轮缩放；俯视模式支持平面查看。
- “自由飞行”可在地图内部自由观察：V 或按钮进入 / 退出；进入后点击画面接管鼠标，直接移动鼠标转向，Esc 只释放鼠标并保留飞行模式。未锁定时也可按住左键拖动转向，无需右键。WASD 前后左右移动，Q 下降 / E 上升，Shift 加速；速度可在面板调整。移动键仅在画面聚焦且已接管鼠标或开始左拖后生效，不占用属性输入框。
- 鼠标接管成功、等待、失败会分别显示；浏览器未允许接管时仍可左键拖动，不会自动反复请求。点击面板、编辑属性、保存、失焦或切到后台只暂停输入、释放鼠标并清空按键，保持飞行模式和相机；点回画面继续，无需再次按 V。取消导入文件选择也保留模式；实际加载场景会重置视图。
- 自由飞行不做碰撞阻挡，可以穿墙查看；切换俯视、聚焦或导入文件时会退出飞行，避免两套相机控制冲突。
- “聚焦路点”与“查看全图”切换取景；高度切片可以移除屋顶和上层。
- 点击路点或输入编号，查看真实 XYZ、节点属性、出边和入边。
- 连接按方向分别显示，两个方向的 JUMP 等标志可以不同。颜色与游戏内路点叠加层一致。
- “显示基础贴图”默认开启，关闭即可切回灰模；可开关物件、编号、路点穿墙显示，并调整地图透明度。
- 界面导入的原始文件快照保存在内存中，编辑作用于工作副本；外部修改原文件后可重新导入。命令行 / 启动器直接打开的文件可用“重新读取路点”从磁盘重载。修改地图或模型资源后需重新导入或重启工具。
- 导入失败会明确显示错误；已有场景保持原样，并标明它是上一次成功导入的场景，不会冒充本次导入结果。

## 编辑与保存

- 选中路点，在右侧修改半径（0–255 的整数）及 Flags，点击“应用修改”。颜色与真实半径圈立即更新，视角和地图贴图保持原样。
- 用“撤销 / 重做”恢复操作；非输入框内支持 Ctrl+Z、Ctrl+Y / Ctrl+Shift+Z。每次应用作为一条命令，保存状态与撤销历史独立。
- Flags 复选框由后端字段 schema 生成，未识别的位会显示并保留；本阶段不会清掉未知位。坐标、mesh、gravity、方向连接、空槽、作者原始字节及尾部数据均保留。
- 浏览器支持直接写入时，首次“保存”会让你选择目标文件；之后保存写入该目标。“另存为”每次重新选目标。只有文件写入并关闭成功才清除未保存标记；取消 / 失败仍保留修改。
- 直接保存成功后，“重新读取保存文件”会从当前保存目标重载，不会退回原导入快照。
- “下载副本”始终主动下载当前路点的 `.agpw` 副本，永不覆盖原文件或当前保存目标，也不改变保存 / 重载目标。下载后保留已有的未保存标记；要查看下载的文件，请重新导入该副本。
- 若浏览器不支持直接写入，“保存 / 另存为”会改为下载副本，同样提示原文件未改，工作区仍未标为已保存。
- 未保存时导入、重载或离开页面会提示丢弃修改。工具不会自动保存，也不会自动重载游戏里的路点；保存到游戏目录后，在游戏内按现有方式重新加载。

实现扩展入口：`agpw3d_document.py` 的字段定义负责验证及字节写回，`agpw3d_web/waypoint_editor.js` 的字段 registry / 命令历史负责编辑状态；以后增加属性时扩展对应字段与控件即可。位置、增删点和连线等结构性修改仍需单独实现相关命令与校验。

## 基础贴图与几何范围

地图基础面、位移地形和 brush 实体的初始变换由 BSP 读取；静态物件及模型实体从游戏资源中读取三角形。地图和模型按 UV 显示 VMT 的 `$basetexture` 对应 VTF；必要的 Patch / include / insert / replace 用于找到基础贴图。其余材质参数和 Source 着色器效果一律忽略，使用工具自身照明；贴图按不透明首帧显示，缺失或无法解码的材质回退灰色并提示。当前地图内嵌 ZIP 按引擎地图挂载规则位于最前；外部模型资源只使用 `gameinfo.txt` 中包含 `GAME` path ID 的 `SearchPaths`。目录和 VPK（包括分卷）严格保持配置中的混合顺序，同名资源命中第一项；`custom/*` 等通配项展开后，目录和 VPK 统一按字母序插入原位置。仅 `MOD` / `PLATFORM` 等条目不作为模型搜索来源。不自动加入未声明的游戏目录，也不猜测其他包；缺少或无法解析 `gameinfo.txt` 时明确报错。不读取游戏进程或链接游戏 DLL。

几何用于观察布局，不是游戏运行时碰撞模拟。模型采用 body 0 / LOD 0 的静态姿态；门、可移动物件、可破坏物和脚本状态不会动态模拟。缺失或不支持的模型会列出提示，并用橙色标记或已知边界框显示占位，避免静默消失。包围框和可见网格均不能替代游戏里的实际通行验证。

地图和模型只读；路点仅在用户显式保存 / 导出时生成修改后的 AGPW，不会自动连线或补跳跃标志。场景几何保存在内存中，源码目录不生成模型缓存或部署文件。

贴图从当前 GAME 搜索路径和地图内嵌资源读取。预览优先使用较低分辨率的现成 mip；PNG 与几何均在内存中，不生成解包目录。解码后的贴图以内容哈希作有容量限制的内存缓存，重复导入可复用，不会因两个地图使用相同文件名而误用旧图。首次加载贴图会比灰模更久。

## 检查

```powershell
py -B tools/agpw_view3d.py "D:\waypoints\cs_office.agpw" --stats
py -B -m unittest discover -s tools -p "test_agpw*.py"
```

`--stats` 完整读取地图与模型后输出数量、缺失资源及格式问题，不启动浏览器。加 `--json` 可输出场景清单。

文件格式实现依据本地 SDK 的 `public/bspfile.h`、`public/gamebspfile.h`、`public/studio.h`、`public/optimize.h` 与 `utils/vrad/vradstaticprops.cpp`，不依赖 SDK 构建产物。Three.js r160 按 MIT 许可随附，来源与许可证见 `agpw3d_web/vendor/`。
