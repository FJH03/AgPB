# 按地图类型规划路点

地图类型按实际玩法确认，`de_`、`cs_`、`zm_`、`ze_` 用作索引。制图和交付入口见 [路点工作流](../README.md)，同队逐方向实走见 [路点实走验收](route-validation.md)，各图的验收结果见 [PROGRESS.md](../../PROGRESS.md)。

## de 爆破

- 从 T / CT 出生区域分别覆盖各真实包区的进场、回防、转点和撤离路线。在可实际安放的位置布置 `GOAL`，从包区核对到实际爆炸伤害范围外的撤离路线。用 `agpb_objectives` 核对地图目标与伤害半径来源。
- `de_dust2` 的分区清单包括 T 后场、A 大 / 坑、A 小、中路、上下 B 洞、B 区 / 窗口 / 后场、CT 连接及 A/B 包区。跨层支路按实际高度分别规划。
- 专项验收核对真实落地 C4 拾取、各包区安放与拆除、T / CT 撤离后在同回合真实爆炸中存活。指定路线与具体包区的证据按实测范围记录。[爆破目标回归](regression-checks.md#爆破目标)

## cs 人质救援

- 覆盖 CT 出生至各人质位置的接近路线、人质位置至真实救援区的护送路线，以及 T 出生至人质区及其入口的巡防路线。用 `agpb_objectives` 核对人质和救援区，将 `RESCUE` 放在实际救援区内的可达位置。
- 护送优先规划人质可连续跟随的通道。梯子、跳落、窄门及多层捷径可按单人路线核对，其护送可用性需用真实跟随确认。
- 普通模式已有跟随与护送逻辑。验收时核对同一活人质从无人跟随变为跟随指定 CT bot，再随行进入救援区并确认实际获救。观测不足的路线标为未验证。[目标状态命令](../../COMMANDS.md)

## zm 僵尸生存

- 按实际地图核对出生区和公共通路，再盘点人类驻留点的入口、绕路与撤退出口，以及僵尸可能接近这些位置的地面和多层通道。
- 窄门、梯子、高台、单向跳落与可能依赖推挤、搭人梯或模式移动参数的支路按实际条件记录。可静态核对的普通通路验收几何覆盖，特殊通路列作候选并标明待验证条件。

## ze 僵尸逃跑

- 顺着本图关卡从出生区盘点撤离主线、分岔与汇合、等待区、阶段检查点和终点，分别核对各阶段可到达的楼层及能否返回。
- 按钮、限时门、升降台、载具、传送、单向落点等按本图实际出现的机制记录入口、出口和开启条件。依赖关卡触发或时序的转换列作候选，留待对应阶段实测。

ZM / ZE 沿用同一套 AGPW 格式。默认 `agpb_mode auto` 检测到 ZR 后按 `ze_` 和 `zm_` 前缀选择模式，其他感染图走 ZM。地图 CFG 可以显式覆盖。ZM 自主选点使用现有手工 CAMP。先验同队 bot 的选点、驻守和进出通路，感染后的实战另取样。ZE 自主行为及特殊通路待实现或实测。
